# Resale and packaging model

The pack contains a signed `Syntax.dmg`, Syntax app, local indexer, onboarding,
permission wizard, built-in capability packs, uninstaller, data export, user and
admin guides, privacy notes, troubleshooting, release notes, SBOM, checksums
and a verification receipt.

| Edition | Capability |
|---|---|
| Free | Local search, built-ins, limited personal skills and recipes |
| Personal | Unlimited personal packs, history, styles, BYO and scheduler |
| Professional | Semantic retrieval, MCP, workers, recipes and exports |
| Teams | Shared library, owners, policies, approvals and telemetry |
| Enterprise | SSO, private distribution, retention, audit and support |

Marketplace objects include terminology packs, skills, recipes, styles,
connectors and workers. They may be free, paid, partner-authored,
organisation-private or Syntax-certified.
